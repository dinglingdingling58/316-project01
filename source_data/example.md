# 示例 Markdown 文档

## 第一章 简介

这是一个示例文档，用于测试文档扫描工具。

### 1.1 背景

本项目旨在开发一个多格式文档扫描工具。

### 1.2 目标

- 支持多种文档格式
- 提取结构化元数据
- 生成分析报告

## 第二章 技术方案

### 2.1 架构设计

系统采用模块化设计，主要包含以下组件：

1. 文件扫描模块
2. 内容解析模块
3. 报告生成模块

#### 2.1.1 扫描模块

负责递归遍历目录，识别文件类型。

#### 2.1.2 解析模块

针对不同文件类型进行内容解析。

### 2.2 代码示例

```python
def hello_world():
    print("Hello, World!")
```
